# Support

This is a volunteer-maintained, pre-1.0 open-source project. Support is
best-effort and does not replace a qualified automotive professional.

## Usage and design questions

Use [GitHub Discussions](https://github.com/ayhammouda/obd-mcp-server/discussions)
for setup help, simulator usage, MCP client configuration, driver interfaces,
profile design, and community ideas. Search existing discussions before
starting a new one.

Share only sanitized configuration and simulator output. Do not post VINs,
vehicle captures, credentials, proprietary diagnostic data, copied standards,
OEM material, or raw commands.

## Bugs and feature requests

Use the repository's
[issue forms](https://github.com/ayhammouda/obd-mcp-server/issues/new/choose)
for reproducible, sanitized bugs and scoped feature proposals. A good report
includes the version or commit, platform, transport, expected behavior,
observed behavior, and a minimal simulator reproduction.

Requests for vehicle writes, clearing, resets, session changes, security
access, routine or actuator control, coding, flashing, gateway bypass, or raw
command access are out of scope.

## Security and safety-boundary reports

Use GitHub's private
[Report a vulnerability](https://github.com/ayhammouda/obd-mcp-server/security/advisories/new)
flow for suspected policy bypasses, data exposure, supply-chain compromise, or
other security-sensitive behavior. Follow `SECURITY.md` and do not disclose
details publicly.

## Vehicle interpretation

The project returns diagnostic observations and uncertainty. It cannot
determine that a vehicle is safe to drive. Consult a qualified professional
for diagnosis, repair, or safety decisions.
